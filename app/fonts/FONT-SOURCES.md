# Font sources

- Cabinet Grotesk variable (100–900), supplied by Fontshare: https://www.fontshare.com/fonts/cabinet-grotesk
  Downloaded from the official Fontshare CDN through its variable-font stylesheet. Refer to Fontshare for the applicable font terms.
- Syne variable (400–800), supplied by the Google Fonts repository: https://github.com/google/fonts/tree/main/ofl/syne
  SIL Open Font License, included in Syne-OFL.txt.

Both fonts are self-hosted through next/font/local, with font-display: swap. Cabinet Grotesk uses --font-portfolio; Syne uses --font-headings.
